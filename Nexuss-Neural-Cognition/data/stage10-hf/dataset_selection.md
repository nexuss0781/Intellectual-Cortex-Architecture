# Stage 10 Corrective Dataset Selection

## Selected dataset

The corrective Stage 10 SFT pilot uses **`databricks/databricks-dolly-15k`** from the Hugging Face Hub. The official dataset card identifies it as a 15,000-row English text instruction-following dataset with `instruction`, `context`, `response`, and `category` fields. The declared Hub license is **CC BY-SA 3.0**. The dataset card describes the records as instruction-following examples generated by Databricks employees and identifies question answering and summarization among its tasks.

The raw source is pinned to the Hugging Face dataset repository and file:

```text
https://huggingface.co/datasets/databricks/databricks-dolly-15k
https://huggingface.co/datasets/databricks/databricks-dolly-15k/resolve/main/databricks-dolly-15k.jsonl
```

The corrective run will download the public JSONL file, record its SHA-256 hash, preserve the original license and attribution metadata, and create a derived governed release with deterministic train/development/held-out splits. The derived release will retain the CC BY-SA 3.0 attribution/share-alike obligation and will not be labeled production-approved merely because the source is public.

## Selection rationale

Dolly 15k is selected because it has a clear dataset card, an explicit machine-readable license tag, a simple JSONL format, a defined instruction-response schema, a manageable size for CPU-bounded experimentation, and multiple task categories suitable for structured response learning. It is more appropriate for the corrective SFT demonstration than an unlicensed or unclear web-scale corpus.

It is English-only and contains employee-generated instruction data rather than the target production domain. It therefore cannot establish multilingual or production-domain readiness. The Stage 10 corrective gates will report those limitations explicitly and will evaluate only the declared English structured-response objective.

## Data-governance controls

The ingestion path must verify the license tag and source URL, hash the raw file, reject malformed rows, remove exact duplicates, scan for obvious secrets and personal-contact patterns, quarantine unsafe or ambiguous records, separate training from held-out evaluation before training, and record source lineage for every retained row. No hidden held-out row may be read by the training process. The original raw file is retained only as a governed source artifact; the model receives the derived training split.

## Non-claims

This dataset selection does not prove that the data is suitable for every commercial deployment or that every record is free from bias, factual error, or third-party rights concerns. CC BY-SA 3.0 is a real license with attribution and share-alike obligations; it requires legal review for any intended production use. The corrective run is an engineering and research pilot, not a production release authorization.
